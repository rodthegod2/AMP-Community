# AMP Community

A community fork of [AMP (Adammantium Multiplayer Mod)](https://github.com/AdammantiumMultiplayer/AMP) for Blade & Sorcery, with stability fixes, hosting from the game on PC, mod sync, settings sync and an in-game updater.

- Downloads: [GitHub releases](https://github.com/rodthegod2/AMP-Community/releases)
- How to install, host and join: [docs/HOW-TO-PLAY.txt](docs/HOW-TO-PLAY.txt)
- PC (Steam) only for now; Quest support is coming in a later version.
